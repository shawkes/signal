Make music with MIDI.

An open-source desktop sequencer for composing, recording, and editing MIDI on Windows, Linux, and macOS.

View on GitHub Build from source

From first note to finished MIDI

  • Edit in the piano roll

    Draw and move notes, adjust velocity, and automate volume and pan. Mute or solo tracks as you work.

  • Record and audition

    Record from a MIDI controller or click the piano keys to audition instruments and drums with a SoundFont.

  • Take your music with you

    Open and save Standard MIDI Files, or export your arrangement as Ogg Vorbis audio.

Build from source

Signal Uno is written in C# with Uno Platform. Its audio rendering and MIDI input run independently of the editor. Clone the repository and run these commands from its root with the .NET 10 SDK installed.

Read the build and run guide 
dotnet build native/Signal.Native.Uno.slnx -c Release
dotnet run --project native/Uno.App/Signal.Native.Uno.App.csproj -c Release -f net10.0-desktop --no-build

Signal Uno is a desktop fork of ryohey’s signal.
